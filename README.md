## Terra Zero

`terra-zero/index.html` è un piccolo mondo simulato: due persone partono da zero, senza strumenti, e imparano a sopravvivere giorno dopo giorno (fuoco, capanne, caccia, agricoltura, linguaggio, figli). Apri il file nel browser: puoi seguire ogni abitante, dare ordini per la giornata, leggere il diario e usare qualche potere della natura.
